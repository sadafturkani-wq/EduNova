# EduNova — Learn Today. Build Tomorrow.

EduNova is a modern and responsive educational landing page designed for learners who want to explore programming and technology.

## About the Project

EduNova provides a clean, engaging, and student-friendly interface that introduces educational opportunities and encourages learners to develop their technical skills.

## Features

- Modern and responsive design
- Student-friendly user interface
- Attractive visual elements and animations
- Organized sections for learning and exploring technology
- Responsive layout for desktop, tablet, and mobile devices

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap

## Live Demo

https://sadafturkani-wq.github.io/EduNova/

## Project Structure

- `index.html` — Main webpage
- `style.css` — Styling and responsive layout
- `script.js` — Interactive functionality
- `assets/` — Project images and other assets

## Getting Started

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

This project was developed as part of my web development learning journey and demonstrates my skills in building responsive and visually engaging web interfaces.
